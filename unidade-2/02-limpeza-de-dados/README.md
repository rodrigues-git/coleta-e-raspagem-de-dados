# Limpeza de dados de automóveis

## Objetivo

Padronizar valores ausentes, tipos numéricos e categorias de uma base de automóveis com uma classe reutilizável.

## Habilidades demonstradas

Programação orientada a objetos; pandas; padronização de nulos; coerção numérica; normalização textual e diagnóstico de completude.

## Arquivos e dados

- [Notebook com a análise](analise.ipynb)

- `dados/Automobile_data.csv`

Arquivo original fornecido pelo autor. O notebook não registra o endereço de download nem a licença da base Automobile; essa procedência permanece pendente de documentação.

## Como executar

Instale as dependências seguindo o [README principal](../../README.md). Abra `analise.ipynb` no Jupyter e execute todas as células em ordem, com a pasta desta atividade como diretório de trabalho. Os caminhos de dados são relativos à atividade e dispensam Google Drive.

## Resultado verificado

Automóveis: 205 registros, 26 colunas; categorias e nulos validados.
