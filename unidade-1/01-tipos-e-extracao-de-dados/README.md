# Tipos e extração de dados

## Objetivo

Transformar dados textuais, JSON e textos livres em tabelas com tipos adequados.

## Habilidades demonstradas

Conversão de percentuais e estoques; categorias ordinais; normalização de JSON; datas; expressões regulares e extração de informações.

## Arquivos e dados

- [Notebook com a análise](analise.ipynb)

Não exige arquivos locais. Dados sintéticos incluídos no notebook.

Fonte registrada no código: dados sintéticos.

## Como executar

Instale as dependências seguindo o [README principal](../../README.md). Abra `analise.ipynb` no Jupyter e execute todas as células em ordem, com a pasta desta atividade como diretório de trabalho. Os caminhos de dados são relativos à atividade e dispensam Google Drive.

## Resultado verificado

Atas: datas, projetos, orçamentos, prazos e completude conferidos.
