# Consumo da API Rick and Morty

## Objetivo

Consultar personagens e transformar respostas JSON em tabelas, incluindo uma consulta à página 2 com status alive.

## Habilidades demonstradas

Consumo de API REST; parâmetros de consulta; respostas HTTP; JSON; normalização com pandas; tratamento de resultados vazios.

## Arquivos e dados

- [Notebook com a análise](analise.ipynb)

Não exige arquivos locais. Requer acesso à internet para consultar a fonte.

Fonte registrada no código: https://rickandmortyapi.com/api/character

## Como executar

Instale as dependências seguindo o [README principal](../../README.md). Abra `analise.ipynb` no Jupyter e execute todas as células em ordem, com a pasta desta atividade como diretório de trabalho. Os caminhos de dados são relativos à atividade e dispensam Google Drive.

## Resultado verificado

API: página 2 consultada, personagens vivos confirmados.
